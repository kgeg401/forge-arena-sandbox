# Beta 1 — known issues and limits

These boundaries remain after the beta packaging/documentation pass. A beta label
does not promote experimental cards or certify every combination.

| Area | Current boundary | Useful report |
| --- | --- | --- |
| Card interactions | 370 baseline names; 1,590 additional experimental names. Specific choices/targets/presentations can still report a rules gap. | Card names, mode, exact action, expected/actual result and screenshot. |
| Large stacks | Faster local processing keeps normal animation speed. No unconditional 30-second completion limit; required choices and responses still stop progression. | Approximate starting stack size, elapsed time, last prompt and hardware. |
| Repeat combo | Deterministic supported activated-ability sequences only. Real costs apply; changed positions, opposing responses and uncertain results stop new submissions. | Complete demonstrated cycle, chosen count and where it stopped. |
| Match persistence | Returning Home/closing ends the match. Display snapshots are not durable Forge saves; a dead engine cannot be resumed from them. | Last action/error; preserve your saved profile. |
| Internet Commander | Two humans in private rooms; host stays open. No host migration or public queue. Tests through public HTTPS on one PC do not certify arbitrary household networks. | Both release/Arena versions, host/guest role, last visible prompts and whether the connection recovered. Never post the invitation. |
| Commander pods | Extra seats are bots. Ten-player presentation/performance and unusual multiplayer interactions remain experimental. | Living-player count, focused seat, phase and whether a decision is waiting. |
| Zombie Horde | Solo fixed 500-card format. No co-op, custom Horde decks, general paid activations/flashback, optimal-play or balance guarantee. Physical token cards keep Forge's token classification. | Wave, graveyard/board situation and relevant revival/death/copy interaction. |
| Arena compatibility | Only exact pinned standalone/Steam fingerprints are admitted. A future official patch may need a compatibility update. | Selected folder, store, Check Arena output and reported build. |
| Paper artwork | Explicit real-card extensions fetch illustrations into a local cache. Failed first downloads use the native placeholder. | Card name, whether online/cache exists and screenshot; no game assets. |
| Reports | Automatic reporting needs the player's existing authenticated GitHub CLI or an authenticated host relay; otherwise reports remain queued locally. | Fixed error code and release; use a manual issue for detailed gameplay bugs. |

[Submit an issue](https://github.com/kgeg401/forge-arena-sandbox/issues/new/choose)
or start with [troubleshooting](FAQ.md). Review diagnostic excerpts before sharing;
match exports can include private deck/hand information.
