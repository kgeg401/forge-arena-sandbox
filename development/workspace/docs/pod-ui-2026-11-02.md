# Multiplayer presentation refresh - 2026-11-02

Four-player headers and the ten-player opponent rail now share Arena's loaded
artwork and type hierarchy. This is a custom multiplayer layout: Arena does not
provide an official ten-player screen to reproduce.

## Appearance and controls

- Original title and body fonts replace the all-small-caps overlay.
- Each player gets their configured native portrait inside an original profile
  frame, an exact life readout, and hand/library/graveyard/exile icons.
- Original gradient backers, rounded frame artwork and button skins replace
  the solid dashboard boxes. Idle instructional text is removed.
- Gold distinguishes the active player; blue distinguishes priority and legal
  player targets. Normal play no longer draws colored rectangular board lanes.
- Four-player headers remain above the corresponding opponents. The local
  summary stays at lower left. Focus and Table view/Tab keep their old behavior.
- The ten-player rail keeps pinning and automatic follow. On the human's turn,
  it retains the last opponent alongside the human board; its label is Watching,
  rather than incorrectly saying that opponent is taking the current turn.
- Graveyard/exile counters still open original native browsers. Empty zones
  cannot be clicked. During targeting the explicit Attack/Target control remains
  separate from inspection in rail mode. Commander damage retains its existing
  original dialog callback and F5 shortcut.

Only NativeCommanderPodView presentation changed. Forge rules, opponent AI,
card identity, hidden information, native stack/hand/browser implementations,
combat scheduling and elimination/final-four camera policy are unchanged.
No generated or copied game artwork is added to the repository; runtime code
resolves the owned installation's sprites and fonts and fails explicitly if
required artwork is unavailable.

is under the local ForgeArenaPodUi-20261102 folder, outside the repository.
Builds use the pinned installed managed assemblies and C-drive build outputs.

spectator/cache checks, real four- and ten-player navigation callbacks with

The installed client, current user match, GitHub releases and update channel
